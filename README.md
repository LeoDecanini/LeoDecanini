Construyo sistemas a medida, soluciones con IA y herramientas para agencias.
En [MoveUp Digital](https://moveup.digital) desarrollo productos de punta a punta: la web, el panel de administración, la API y la app del celular.

### Inteligencia artificial

- **Bots de WhatsApp con IA**: atienden, recomiendan productos y responden con datos reales del negocio, las 24 horas.
- **IA dentro de los sistemas**: integro modelos como Claude y Gemini en apps y paneles, propios y de clientes.

### Herramientas para agencias

- **Organizador MoveUp**: panel para ordenar el contenido de Instagram de cada cliente: cuentas, publicaciones, copys, anuncios y calendario.
- **Maquetador**: maquetas navegables para mostrarle a cada cliente su proyecto en menos de 24 horas.

### Sistemas a medida

- **ModoUp**: gestión para entrenadores personalizados (virtuales y presenciales) y gimnasios, con app para el alumno: rutinas, pagos y seguimiento.
- **MoveUp Distribuidoras**: SaaS multiempresa para distribuidoras: pedidos, stock y clientes, con un bot de WhatsApp que toma pedidos y pasa la charla a una persona cuando hace falta.
- **Sistema de turnos**: reservas online multirrubro, con facturación electrónica conectada a ARCA, recordatorios por WhatsApp y bot de atención.
- **App de viajes tipo Uber**: app de pasajero y conductor en Flutter, API en NestJS con tiempo real y mapas.
